# 🚀 auto-prompt-backoffice

A lightweight, enterprise-focused open-source toolkit designed to bridge the gap between advanced LLMs (like Claude) and daily back-office operations (HR, Corporate Planning, Internal Operations).

This repository provides production-ready prompt templates, automated data processing scripts, and orchestration pipelines for high-context report generation and internal survey analytics.

## ✨ Key Features
- **PDR/RCA Framework Automation:** Pre-built structured prompt templates for Plan-Do-Review (PDR) workflows and Root Cause Analysis (RCA).
- **Context-Heavy Report Generator:** Optimized token-payload management scripts for drafting long-form internal newsletters and executive report summaries.
- **Survey Sentiment & Insights Analyzer:** Python-based automation scripts to process bulk survey data and extract actionable insights using LLM APIs.
